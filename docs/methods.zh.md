# 细胞计数方法

[English](methods.en.md) · [使用指南](guide.zh.md) · [仓库首页](../README_中文.md)

模块 **1.0.0** 将两类观察组织为细胞记录：DAPI 核，以及从辅助通道独立识别的胞体。核与胞体在原图坐标下满足唯一对应关系时，组成同一个细胞；符合条件的胞体也可以在没有检出对应 DAPI 核时单独计数。最终总数来自已接受的细胞记录。

## 输入与坐标

主软件从无符号 8 位或 16 位多通道 TIFF 中选取一个图像组和一个时间点，向引擎提供 DAPI 通道、与其不同的辅助通道、辅助标记物名称，以及用于显示的通道和颜色。多层图像需要实际 X、Y、Z 物理标定；真实单层图像需要 X、Y 标定，并按可用的平面证据处理。桌面输入检查还要求多层图像的 XY 采样为方形像素。

科学掩膜始终使用原始图像网格，坐标、物理距离和逐 Z 交点均对应原图。辅助标记物名称记录用户对通道的声明；eGFP、Biocytin、ALDH1L1 和自定义名称不会切换隐藏的算法分支。显示颜色和通道可见性只改变审核画面。

## 从全栈定位局部计算区域

引擎扫描所需通道的全部原始 Z 层，计算 8 × 8 和 16 × 16 XY 块的精确强度统计，并保留边缘块的实际像素数；同时为选中的显示通道生成全栈最大强度投影。这些统计用于定位信号聚集并安排原像素计算，统计区域本身不计作细胞，也不作为分割输入。

DAPI 定位使用 16 像素块统计，在各 Z 层保留超过阈值的信号聚集区域。较大区域拆分为有界计算窗口，同时保留全部合格前景。每个局部事件提供一个 Z 范围和 XY 位置。这个 Z 范围确定从哪里开始调查；对象实际的轴向范围由后续原体积恢复确定。

## 获取局部 DAPI 模型证据

引擎对每个保留事件，在该事件的局部 Z 范围内对原始 DAPI 灰度取最大值。固定模型通常接收来自真实原图的 256 × 256 XY 窗口；仅当原图某一轴本身小于 256 像素时才进行计算补边，并在生成掩膜前裁去补边。每个特征图使用其实际第 1 和第 99 百分位归一化一次。

固定配置如下：

| 项目 | 当前取值及作用 |
|---|---|
| Cellpose 软件包 | `4.2.1.1` |
| 模型 | `cpsam_v2` |
| 模型 SHA-256 | `0f1cc3f7ecdd8a037a57c6c48d9d8921391be4cbce3fa9f13c3e3a2e1253c667` |
| 模型模式 | 二维推理，`do_3D=False` |
| 主掩膜阈值 | `cellprob_threshold=0.0`、`flow_threshold=0.4` |
| 弱候选阈值 | `cellprob_threshold=-2.0`；仅在主掩膜未覆盖定位种子时使用，新增候选需要审核 |
| 空间采样 | 保留原始 XY 和 Z 采样，不按物理尺寸缩放图像 |

主候选和弱候选复用同一组模型流场与得分。如果观察到的掩膜接触模型窗口内部边界，引擎会读取最多 384 × 384 像素的真实原图上下文，再执行一次有记录的检查。原观察保留，额外上下文是否解决边界限制也被记录。用于显示的全栈投影不进入这条推理路径。

## 在原体积中恢复核

二维模型掩膜约束核的横向身份。引擎随后读取事件周围的原始 DAPI 体素，测量三维局部信号聚集。它以各层中位数定义信号事件，再使用物理标定后的高斯核平滑其占据分布，带宽为 0.568 µm。该带宽规定测量尺度，不代表预设核直径。

连通的密度区域形成候选三维区域族。只对应一个模型标签的区域族，即使内部存在多个强度峰，也保留为一个事件；多个模型标签共享同一区域族时，使用各标签对应的实际密度峰作为分水岭种子进行分离。互不连通的区域族保留不同事件身份。没有匹配模型证据的区域族记录为调查位置。

当观察到的密度或轴向端点证据需要更多上下文时，恢复步骤会扩大原图读取窗口；仍未解决的身份与边界证据进入审核记录。不同窗口中重叠的核观察按实际掩膜协调：共享原图区域内双向重叠比例均至少为 0.5 时，可以认定为重复观察；存在竞争重叠时保留歧义。每个最终核观察保存一个代表点，并在掩膜实际相交的每个原始 Z 层上保存内部锚点。

## 测量核周辅助信号并独立识别胞体

所选辅助通道承担两项不同工作。

第一，引擎测量每个已恢复核周围的荧光。沿核表面向外取样，以物理表面积加权，记录近核接触、连续阳性信号的厚度及其跨 Z 层分布。当前规则允许 0.6 µm 的接触间隙，并要求 1.2 µm 的持续信号深度；测得的接触比例、厚信号覆盖率、有效采样和 Z 支持共同决定该观察为接受、待审核或排除。远处不连续的信号不能补足连续信号段。完整判定参数见 [`support.py`](../engine/leap_cell_counting/support.py)。

第二，独立路径在辅助通道中定位信号聚集，再检查对应原始像素。它测量局部背景和信号幅度，构建厚度几何，按条件合并相邻厚度区域，并识别空间上可分辨的紧凑核心。胞体观察需要与该核心关联的实测辅助通道阳性像素。核心触及计算窗口边界时，程序请求更多真实原图上下文。实测荧光掩膜与用于关联的几何包络分别保存；几何构建中的闭腔处理不会制造荧光阳性体素或核掩膜。

这两条路径共享一次原图统计扫描，可以并行执行。胞体识别无需先检出 DAPI 核或 Cellpose 掩膜。引擎保留全部合格计算区域；容量不足会终止任务，不输出缺失部分区域的计数。

## 全局解析细胞身份

引擎在原图坐标下测量每一对可能关联的核与胞体。几何匹配需要同时满足：

1. 核代表点位于胞体关联包络内部。
2. 核的全部最大内部距离核心体素均位于该包络内部。这个核心由观察到的核掩膜中、按物理距离计算的最深内部体素组成。
3. 核代表点所在的原始 Z 层上存在实际胞体阳性像素。

解析器再检查全部候选关系。只有核和胞体双方都唯一对应，且没有未解决的竞争关系时，才合并该配对。部分包围或竞争关系保留为分开的待审核记录；代表点和整个核心均位于包络之外时，判为不匹配。整核被包围比例作为测量值保存，质心接近或跨类别掩膜重叠不足以单独确定身份。

唯一配对的核与胞体形成一个含两份来源观察的细胞。未配对但已接受的胞体仍可计数。细胞在各 Z 层的锚点来自该层实际存在的观察：有胞体证据时优先使用胞体锚点，其他层仍保留核交点。因此，同一细胞可以出现在多个 Z 层，总数只增加一次。

## 审核状态与保存的证据

只有未删除且 `status="accepted"` 的细胞计入总数。当核周辅助信号通过接受规则，且算法设定的 XY 搜索区域边界是唯一剩余限制时，`review_hint="likely_astrocyte"` 将该对象列为 High Likelihood，与其他待审核对象区分。这个提示本身不接受对象。[使用指南](guide.zh.md)说明四种界面标记及改变计数的操作。

`labels.npy` 和 `body-labels.npy` 分别保存原图 ZYX 网格上的核标签与胞体标签。标签整数必须与所属文件的标识符一起解释。细胞 ID 标识逻辑记录；可见的 `display_no` 则随当前计数重新生成连续编号。人工接受保留原细胞 ID 和掩膜；人工合并生成新细胞 ID，并保留父对象的来源观察。删除和撤销只调整标注，不改写科学掩膜。

`analysis.json` 记录输入、模型、通道选择、物理标定及标签文件注册表；`observations.json` 保留来源观察和测得的关联关系；诊断及计算账本保留参数与处理证据。确认保存的会话保留全部审核状态及编辑历史，CSV 和编号 PNG 只包含计数对象。精确持久化字段见[身份契约](prototype-d/CELL_IDENTITY.md)，导出列见[使用指南](guide.zh.md)。

## 证据适用范围

上述阈值和几何规则描述当前实现的开发方法。现有真实数据评估使用 Biocytin，不能据此确定其他可选标记物的表现；核—胞体关联仍待有代表性的人工标注真实掩膜验证。因此，Astrocyte 和 Neurons 是界面工作流类别，不代表经过独立验证的生物学细胞类型。真实单层输入保留二维证据，不作轴向体积判断。
